# AuditAI Busan

공공기관·국립대 등 **예산 집행 상담 · 증빙 요청 · 접수 체크 · 판정**용 웹앱입니다.

## 바로 시작 (로컬)

1. **`시작하기.bat`** 실행 → `http://127.0.0.1:8765/index.html`
2. **1 문서등록**: ①지침·매뉴얼 / ②증빙 서식(HWP·PDF) 분리 업로드
3. **2 상담**: **간략한 예산 설명** → 비목 자동 추정 → 해당 비목 입력만 표시 → 답변 생성(쪼개기 점검 포함)
4. **3 증빙요청**: 전체 요청 / **미비분만 추가요청**(다 받을 때까지 반복) · **AI 메일 다듬기** · `.eml` 서식 첨부
5. **4 접수점검** → 건수별 선택·필터 · 그 건만 누적 접수 → **5 집행판정**

### AI (선택)

`.env`에 `OPENAI_API_KEY=` 입력 후 `시작하기.bat`으로 **server.py** 실행.
- `/api/counsel` — 상담 해설(판정은 규칙엔진 유지)
- `/api/mail` — 증빙 메일 문장만 다듬기(서류 목록·사실 불변)

Vercel 배포 시에도 같은 키를 **Project → Settings → Environment Variables**에 넣으면 AI가 동작합니다.

## 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 앱 본체 |
| `server.py` | 로컬 정적 파일 + `/api/*` |
| `api/` | Vercel serverless (`health` / `counsel` / `mail`) |
| `.env` / `.env.example` | API 키 (공유·커밋 금지) |
| `시작하기.bat` | 로컬 서버 실행 |
| `사용안내.md` | 실무 매뉴얼 |

브라우저 데이터는 접속한 PC의 저장됩니다.
